# 重整文档导航

## 整理原则

`doc` 目录下保留原始改造记录，不移动、不删除，方便按历史过程溯源。

`redoc` 目录按当前项目能力重新整理，采用“一个大功能点一个文档”的方式。每个专题文档不是摘要，而是把对应功能点下的原始文档内容按来源文件合并在一起，并在开头保留来源索引。

## 阅读建议

- 想快速了解当前项目能力，先读 `00-项目总览.md` 和对应专题文档开头的“整合说明”。
- 想查详细改造过程，直接在专题文档内按“原文：xxx”定位。
- 想追历史源文件，回到 `doc` 目录查看同名原始文档。
