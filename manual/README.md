# 项目使用手册

这个目录面向第一次拉取项目、准备启动环境和快速开发业务的人。

- [项目使用手册](./项目使用手册.md)：从环境准备、数据库初始化、后端启动、前端联调，到新业务开发、代码生成、文件上传、日志排查和部署建议。
- [开发示例手册](./开发示例手册.md)：按官网文档风格整理常用开发场景，提供 Controller、DTO、MapStruct、文件上传、前端组件、日志、部署等代码示例。
- [../redoc](../redoc)：按功能点整合后的改造设计文档，适合需要理解实现细节、追溯改造原因时阅读。
- [../doc](../doc)：历史改造过程文档，保留原始资料，方便溯源。

建议新成员先读 `项目使用手册.md`，按“快速启动”跑通项目后，再打开 `开发示例手册.md` 照着示例开发第一个业务模块。需要理解改造原因时，再查看 `redoc/` 中的专题文档。
